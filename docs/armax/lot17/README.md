# Armax — lot 17 en cours de production

Cette continuation repart du lot 16 publié au commit `c1124d45bbe265eec07646db1a705d2381e4cb51` : 192 fiches, 132 avec image candidate et 60 sans image. Le [plan de production](production-plan.json) traite les 34 fiches manquantes non exclues. Les 26 exclusions précédentes restent conservées.

Les fichiers sont enregistrés au fur et à mesure avec leurs prompts et références dans `source-me1-me2-mea`, `source-me3` et `source-costumes`. Ces dossiers peuvent être incomplets pendant la production. Le catalogue courant reste celui du [lot 16](../lot16/production-catalog.json) jusqu’à la consolidation finale de ce lot.

Les nouvelles images sont des prototypes fixes. Une présence de fichier ne certifie ni la fidélité 1:1, ni les zones reconstruites, ni l’intégration dans le moteur. Chaque refus est consigné et ne donne lieu à aucun nouvel essai sur le même sujet.

Le lot 17 constitue une nouvelle production. Les originaux du lot 15 restent [non récupérés](../lot16/RECUPERATION_LOT15.md).
